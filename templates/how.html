Как устроена моя нейросеть

Никакой магии: сеть — это куча маленьких формул, соединённых в слои. Разбираю всё по частям, как на уроке.

1 Нейрон

Нейрон — «кирпичик» сети. Он берёт числа на входе, умножает каждое на свой вес (вес — это «важность» числа), складывает, добавляет смещение b и прогоняет сумму через сигмоиду:

y = sigmoid(w1·x1 + w2·x2 + … + wn·xn + b)

В моей сети таких нейронов 25, а весов у них — 161.

2 Сигмоида

Сигмоида сжимает любое число в диапазон от 0 до 1, поэтому ответ нейрона удобно читать как вероятность: 0.91 — «на 91% уверен». Попробуй сам: подвинь ползунок и посмотри, куда попадает точка.

x = 0.0  →  sigmoid(x) = 0.500

Формула: 1 / (1 + e-x). Когда x большой — ответ почти 1, когда сильно отрицательный — почти 0.

3 Архитектура: 8 → 16 → 1

Слева — 8 признаков клиента (месяцы, покупки, чек, давность, жалобы, скидки, корзины, письма). В середине — 16 нейронов скрытого слоя, каждый выучил свою комбинацию признаков. Справа — один выход: риск ухода от 0 до 1.

Линии — это веса. Их 161, и при обучении каждый потихоньку «подкручивается» в нужную сторону.

4 Как проходит обучение

1. Прямой проход

Клиент проходит через сеть, она выдаёт ответ — например, риск 0.2.

2. Ошибка

Сравниваем ответ с правдой: если клиент ушёл, а сеть сказала 0.2 — промах большой.

3. Backpropagation

Идём от выхода к входу и считаем «вину» (delta) каждого нейрона в этом промахе.

4. Подкрутка

Каждый вес сдвигаем чуть-чуть против ошибки. И так 400 раз по всем 1000 клиентам.

Это называется обратным распространением ошибки. Самое сложное было понять, зачем там производная сигмоиды — она показывает, насколько сильно можно «крутить гайку» в этом месте.

Три хитрости

Нормализация. Все признаки сжимаются в 0..1, иначе средний чек (12 000) задавил бы число жалоб (2).

Балансировка. Ушедших всего 26%, поэтому при обучении я дублирую их, иначе сеть слишком часто отвечает «он останется».

Экзамен. 20% клиентов сеть не видит при обучении — только так честно меряется точность.

Настоящий код из проекта

Так выглядит сигмоида в моём neuronet.py:

def sigmoid(x):
    if x > 30.0:
        return 1.0
    if x < -30.0:
        return 0.0
    return 1.0 / (1.0 + math.exp(-x))
